# «Готово» только после проверки

Проверяется сам результат, а не намерение.

- Файл существует, результат инструмента прочитан и это не ошибка.
- Заявленное свойство (размер, цвет, количество, сумма) измерено сейчас, а не взято из памяти о прошлом шаге.
- Проверить нельзя: так и написать, а не выдавать за сделанное.

## Что проверять в Agent Office

**Сервер (`server.py`):**

```bash
npm test
```

**Отрисовка (`src/*.ts`):**

```bash
npm run check
npm run build
python3 server.py --port 8768
```

Открыть http://localhost:8768 и посмотреть глазами. В консоли браузера не должно быть ошибок. Не забыть положить в коммит собранные `web/*.js`: они лежат в репозитории и нужны тем, кто запускает проект без `npm`.

**Приложение строки меню (`menubar/`):**

```bash
scripts/build-menubar.sh 8768 && open build/AgentOffice.app
```

**Статистика и окошко строки меню:** страница `http://localhost:8768/menubar.html` открывается и в обычном браузере.

Запускать проверку на отдельном порту: основной экземпляр на 8767 может держать приложение строки меню.
