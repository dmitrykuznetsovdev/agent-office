# Agent Office

Пиксельный офис, в котором видно, как работают агенты [Claude Code](https://claude.com/claude-code) и [Codex](https://openai.com/codex): кто сидит за столом, что делает прямо сейчас, кто сдал работу и сколько это стоило.

Сервер читает журналы, которые Claude Code и Codex и так пишут в `~/.claude/projects` и `~/.codex/sessions`. Видны все сессии сразу: из терминала, из приложения, из любой папки. Хуки и плагины не нужны, в журналы ничего не пишется.

Считаются только сессии этих агентов. Обычные чаты claude.ai и ChatGPT сюда не входят: токенов и трат по ним нигде нет.

## Что на экране

- **Сессии за сутки** — справа: название, папка, сколько агентов в работе, сколько потрачено. Цветная полоса и подпись показывают, чья сессия, а фильтр «Все · Claude · Codex» оставляет одного провайдера и показывает его траты за сегодня. Клик открывает офис сессии; галочка «следить за активной» переключает офис сам.
- **Офис по этажам** — здание: наверху кабинет руководителя (главная сессия), под ним этаж на каждый отдел, внизу холл с лаунжем. У каждого агента своя ячейка: что делает («правит cuts.json», «$ npm test») со значком, модель (Haiku, Sonnet, Opus, Fable), сколько потратил, облачко с анимацией над головой, стол и имя. Ничего не налезает друг на друга; пустые отделы сворачиваются в полоску.
- **Режим дня** — по журналу: запись меньше минуты назад — работает, до трёх минут — думает, до десяти — пьёт кофе у кулера, дольше — спит за столом. Сдал работу — галочка, папка едет пневмопочтой наверх, сам идёт в лаунж, через полчаса — домой. В холл и обратно агенты ходят по коридору и ездят на лифте.
- **Деньги** — купюра и сумма у каждого стола, монетки летят к работающим, сумма отдела на маркерной доске этажа, итог на крыше.
- **Вид** — три офиса («Уютный», «Бизнес-центр», «Лофт») и время суток: по часам или утро, день, вечер, ночь.
- **Фриланс** — универсальные агенты (`general-purpose`, `Explore`, `Plan` и т. п.), свой этаж.
- **Журнал** — последние действия руководителя и агентов.
- **Скриншот** — кнопка с камерой в шапке снимает только офис выбранной сессии: всё здание целиком, даже если оно не влезает в окно. В картинке только офис. PNG со смешным названием по настроению офиса («Все на кофе», «Кипит работа») ложится в `~/Pictures/Agent Office/` и копируется в буфер обмена. Если сервер не смог записать файл, картинку скачает браузер.
- **Codex** — то же здание с голубой вывеской. Модели получают те же грейды: Luna, Terra, Sol, Astra. Тред авторевью сидит за столом «Контролёр», запущенные агенты — во фрилансе.

## Офисы папок

У каждой папки один штат и один офис, а сессия показывает столы тех, кого она может позвать или уже звала.

- **Штат** собирается без модели: состав из самой свежей сессии папки и файлы агентов (плагины, `.claude/agents`, `~/.claude/agents`): роль из заголовка `# Роль`, описание, инструкция, модель. Отключённые плагины и плагины других проектов в штат не входят.
- Пока офиса нет, столы расставлены автоматически: отделы по роду работы, должности из словаря.
- Кнопка **«Сгенерировать офис»** отдаёт Claude (`claude -p`, Sonnet, без инструментов, ваших хуков и настроек) не только список агентов, но и их инструкции, скил руководителя, строки `CLAUDE.md` про агентов и историю вызовов. Обычно 10–30 секунд и несколько центов, потолок — 50 центов. Сборка идёт в фоне: видно, сколько прошло, её можно отменить. Если не вышло (нет связи с API, claude не залогинен, не успел за 2 минуты), офис остаётся прежним, а под переключателями — причина и «Повторить». Прежний офис можно вернуть кнопкой «Вернуть прежний».
- **Новый агент садится сам.** Раз в 30 секунд сервер сверяет штат с офисом. Новичок сразу получает стол рядом с коллегами по плагину, затем одна генерация уточняет его отдел и должность; остальных она не двигает. Для папки без офиса деньги сами не тратятся. Отключить для папки: `"auto": false` в файле офиса.
- **Что остаётся при пересборке.** Должность из `# Роль` файла агента, прежние должности, закреплённые столы. Агенты общих плагинов в проекте со своей командой сидят на этаже ПОДДЕРЖКА.
- **Закрепить вручную:** `"locked": true` у стола, стол не сдвинется и не переименуется. Закрепить вывеску: `"titleLocked": true`. Манифест проекта `.claude/office.json` задаёт то же из репозитория: `title`, `boss`, `zones` со столами; он главнее модели.
- **Языки.** Раскладка держится на типах агентов и `id` отделов, подписи лежат в `name` и `short`. У офиса есть поле `lang` (`ru`, `en`): подписи не на этом языке отбрасываются.
- Сервер, запущенный из приложения строки меню, зовёт `claude` без вашего терминала. Прокси он берёт из вашей оболочки (`$SHELL -c env`), а если там его нет — из системных настроек macOS. Если генерация висит, проверьте в обычном Терминале `claude -p "привет"`: команда должна ответить, а не попросить войти.
- Офисы лежат в `~/.claude/agent-office/offices/<папка>.json` — обычный JSON, можно править руками. Формат — в [examples/office.example.json](examples/office.example.json).

## Запуск

Нужен только `python3` (3.9+) и браузер. Для генерации офисов — установленный `claude`. Для истории Codex — `zstd` (`brew install zstd`): остывшие журналы он хранит сжатыми. Без него сервер читает свежие журналы, а сжатые дочитает, когда `zstd` появится.

```bash
python3 server.py
```

Откройте http://localhost:8767.

Флаги: `--port 8767`, `--host 127.0.0.1`, `--data ~/.claude/agent-office`, `--shots "~/Pictures/Agent Office"`. Если Claude Code хранит данные не в `~/.claude`, сервер возьмёт `CLAUDE_CONFIG_DIR`, а для Codex — `CODEX_HOME`.

### Статусная панель и автозапуск (macOS)

В строке меню живёт пиксельный офис: рядом траты за сегодня (в целых долларах) и мигающая зелёная лампочка с числом сессий, где сейчас кто-то работает. Клик открывает окошко в стиле офиса с двумя вкладками:

- **Сессии** — «Сегодня» (с полуночи) и сколько сессий в работе, разбивка Claude Code / Codex; ниже «Активные» (запись в журнале за последние 10 минут) и «Раньше сегодня»: сколько потрачено сегодня и сколько всего. Клик открывает офис сессии в браузере.
- **Статистика** — за 7 дней, 30 дней или всё время, по всем провайдерам или по одному: траты по дням (или неделям) с разбивкой по моделям, неделя к неделе, доли моделей, из чего складывается счёт (вход, ответы, чтение и запись кэша), карта «когда тратим» по дням недели и часам, лимиты подписки Codex, папки.
- **Токены** — та же история в токенах, с тем же фильтром провайдера.

Правый клик — служебное меню: перезапуск сервера, лог, автозапуск, выход. Окошко — страница сервера `web/menubar.html`, поэтому её вид меняется без пересборки приложения. Историю трат сервер копит в `~/.claude/agent-office/stats.json`: старые журналы чистятся, а статистика остаётся. Суммы посчитаны по ценам API: по подписке счёт другой. Приложение само поднимает сервер и гасит его при выходе.

```bash
scripts/install-launchd.sh
```

Собирает приложение (`swiftc`, нужен Xcode или Command Line Tools), кладёт его в `~/Applications/AgentOffice.app` и ставит в автозапуск: стартует при входе в систему, после падения поднимается само, после «Выход» — нет. macOS покажет уведомление «Добавлен фоновый объект» — это оно. Лог сервера и приложения — `~/Library/Logs/agent-office.log`. Убрать:

```bash
scripts/uninstall-launchd.sh
```

Только собрать и запустить руками, без автозапуска: `scripts/build-menubar.sh && open build/AgentOffice.app`. Приложение помнит, где лежит репозиторий; после переноса папки — пересобрать.

## Разработка

```
server.py           сервер: разбор журналов, стоимость, офисы, API
web/index.html      страница
web/floors.js       отрисовка офиса по этажам (собирается из src/, лежит в репозитории)
web/menubar.html    окошко строки меню: сессии и статистика
src/floors.ts       исходник отрисовки: холст, кадр за кадром; подписи — на втором холсте поверх
src/office.ts       имена ролей и деньги, общие для страницы и отрисовки
src/shot.ts         названия скриншотов и PNG (→ web/shot.js)
src/menubar.ts      исходник окошка (→ web/menubar.js), графики — SVG
menubar/            приложение для строки меню macOS (Swift, один файл; рисует и свою иконку)
scripts/            сборка приложения, установка и снятие автозапуска
tests/              тесты сервера (unittest)
```

```bash
npm install         # TypeScript для сборки отрисовки
npm run build       # src/*.ts → web/*.js
npm test            # тесты сервера
```

Цены за токены — таблица `PRICES` в `server.py`. Модель без цены (например, `codex-auto-review`) считается в токенах, но стоит $0.
