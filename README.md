# Agent Office

Пиксельный офис, в котором видно, как работают агенты [Claude Code](https://claude.com/claude-code): кто сидит за столом, что делает прямо сейчас, кто сдал работу и сколько это стоило.

Сервер читает журналы, которые Claude Code и так пишет в `~/.claude/projects`. Видны все сессии сразу: из терминала, из приложения, из любой папки. Хуки и плагины не нужны, в журналы ничего не пишется.

## Что на экране

- **Сессии за сутки** — справа: название, папка, сколько агентов в работе, сколько потрачено. Клик открывает офис сессии; галочка «следить за активной» переключает офис сам.
- **Офис папки** — руководитель (главная сессия) и столы агентов по отделам. Агент заходит, садится, печатает, над ним облачко с действием («читает Makefile», «$ npm test»), по окончании — галочка и папка с результатом летит руководителю.
- **Зарплата** над каждым столом и итог сессии в шапке — по токенам из журналов.
- **Фриланс** — универсальные агенты (`general-purpose`, `Explore`, `Plan` и т. п.).
- **Журнал** — последние действия руководителя и агентов.

## Офисы папок

У каждой папки свой офис: какие агенты есть, сервер узнаёт из журнала сессии (список доступных агентов с описаниями).

- Пока офиса нет, столы расставлены автоматически: отдел на плагин, должности из названий агентов.
- Кнопка **«Сгенерировать офис»** отдаёт список агентов Claude (`claude -p`, модель Sonnet, без инструментов, ваших хуков и настроек): вывеска, должность руководителя, отделы, русские должности и предметы на столах. Около 10 секунд и несколько центов.
- Офисы лежат в `~/.claude/agent-office/offices/<папка>.json` — обычный JSON, можно править руками. Формат — в [examples/office.example.json](examples/office.example.json).

## Запуск

Нужен только `python3` (3.9+) и браузер. Для генерации офисов — установленный `claude`.

```bash
python3 server.py
```

Откройте http://localhost:8767.

Флаги: `--port 8767`, `--host 127.0.0.1`, `--data ~/.claude/agent-office`. Если Claude Code хранит данные не в `~/.claude`, сервер возьмёт `CLAUDE_CONFIG_DIR`.

### Статусная панель и автозапуск (macOS)

В строке меню живёт значок офиса: рядом с ним траты за сегодня и сколько агентов сейчас в работе. В меню — открытые сессии и остальные за сутки с ценой каждой; клик открывает офис сессии в браузере. Приложение само поднимает сервер и гасит его при выходе.

```bash
scripts/install-launchd.sh
```

Собирает приложение (`swiftc`, нужен Xcode или Command Line Tools), кладёт его в `~/Applications/AgentOffice.app` и ставит в автозапуск: стартует при входе в систему, после падения поднимается само, после «Выход» — нет. macOS покажет уведомление «Добавлен фоновый объект» — это оно. Лог сервера и приложения — `~/Library/Logs/agent-office.log`. Убрать:

```bash
scripts/uninstall-launchd.sh
```

Только собрать и запустить руками, без автозапуска: `scripts/build-menubar.sh && open build/AgentOffice.app`. Приложение помнит, где лежит репозиторий; после переноса папки — пересобрать.

## Разработка

```
server.py           сервер: разбор журналов, стоимость, офисы, API
web/index.html      страница
web/office.js       отрисовка офиса (собирается из src/, лежит в репозитории)
src/office.ts       исходник отрисовки: SVG одной строкой, анимации SMIL
menubar/            приложение для строки меню macOS (Swift, один файл)
scripts/            сборка приложения, установка и снятие автозапуска
tests/              тесты сервера (unittest)
```

```bash
npm install         # TypeScript для сборки отрисовки
npm run build       # src/office.ts → web/office.js
npm test            # тесты сервера
```

Цены за токены — таблица `PRICES` в `server.py`.
